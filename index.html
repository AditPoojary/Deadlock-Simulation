HOW IT WORKS   /   RESEARCH BASIS

Deadlock: processes permanently wait on resources held by one another. This visualizer models a Wait-For Graph: P1 → P2 means P1 waits for P2. Tarjan's DFS uses discovery indices, low-link values, and a stack to find strongly connected components (SCCs). SCCs with more than one member (or a self-loop) are deadlock groups under these modeled assumptions.

Complexity: O(V + E) time, O(V) space. Educational simulation inspired by "An Enhanced Deadlock Detection Methodology Using Tarjan's Algorithm", IEEE CSITSS 2024, DOI: 10.1109/CSITSS64042.2024.10816916; it is not an exact reproduction of the authors' implementation.
